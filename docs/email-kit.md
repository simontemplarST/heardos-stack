# Authentik branded email kit

Authentik's emails are Django templates. Any file placed in its custom-template volume with the same name as a
built-in replaces that built-in, because the volume is first in Django's template search path. No stage setting is
touched.

## Files (`authentik/email-templates/email/`)

| File | Used for | Variables it must keep |
|---|---|---|
| `base.html` | The theme: layout, inline CSS, palette, header lockup, footer. Blocks: `preheader`, `eyebrow`, `content`, `sub_content`, `footer_note`, `logo_url`. | none |
| `password_reset.html/.txt` | Recovery flow, "Forgot password" | `user`, `url`, `expires` |
| `account_confirmation.html/.txt` | Activation step of invitation sign-up | `user`, `url` |
| `email_otp.html/.txt` | Email-code second factor | `user`, `token`, `expires` |
| `invitation.html/.txt` | Invitation links | `host`, `url`, `expires` |
| `event_notification.html/.txt` | Notification rules | `title`, `body`, `link`, `key_value`, `source` |
| `setup.html/.txt` | The admin console's test email | none |

Each `.txt` is the plain-text part that travels with the HTML, so the text version is branded too.

## Design rules

- Tables for layout, inline styles for anything that matters, a web-safe font stack behind Inter, light background
  only, 560 px wide, one button in the brand orange with ink text, Outlook conditionals, a phone media query.
- The logo is loaded from a public URL (`https://cloud.<domain>/brand/`). Mail clients will not load Authentik's
  tokenised media links or data URIs.
- Django `{# … #}` comments are single-line only. A wrapped one is printed into the email. Use
  `{% comment %}…{% endcomment %}` for anything longer.

## Workflow

1. Edit in the repo.
2. Copy the `email/` folder into the Authentik custom-templates volume on the host.
3. Render every template with sample data inside the container: copy `render.py` in and run
   `docker exec <server> ak shell -c 'exec(open("/tmp/render.py").read())' </dev/null`. It prints size and a brand check
   per template and fails loudly on a template error.
4. Restart Authentik: running workers cache compiled templates.
5. Send a real one by starting the recovery flow for your own account.

The sign-in page background is generated by `authentik/make-flow-background.py` from the mono mark and the palette;
`flow-background.jpg` is its output and goes into the media volume's `branding/` folder.
